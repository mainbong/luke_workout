# LUKE / 90일 운동 미션

2026년 7월 23일부터 10월 20일까지 이어지는 90일·13주 운동 프로그램입니다.
목·금 푸쉬업과 토·일 등 운동의 주간 구조를 반복합니다.

## 실행

React 19, TypeScript 7, Vite 8 기반의 정적 프런트엔드입니다.

```bash
npm install
npm run dev
```

터미널에 출력된 로컬 주소를 브라우저에서 엽니다.

## 배포

GitHub Actions가 `main` 브랜치 변경을 감지해 Vite 빌드 결과를 GitHub Pages에 배포합니다.

저장소의 **Settings → Pages → Build and deployment**에서 Source를
**GitHub Actions**로 설정해야 합니다.

## 페이지 범위

- 운동 목록과 각 운동의 세트·반복·휴식 기준만 보여주는 정적 안내 페이지입니다.
- 개인정보를 입력하거나 저장하는 기능은 없습니다.
- 금요일 푸쉬업 기술 훈련은 연결된 YouTube 영상의 20분 루틴을 따릅니다.

## 프로젝트 구조

```text
.
├── src/
│   ├── App.tsx  # 90일 목표와 요일별 운동 프로그램

├── index.html   # Vite HTML 진입점

├── vite.config.ts
└── README.md
```

## 운동 프로그램 원칙

- 목요일 푸쉬업 미션은 최대 5세트, 세트 간 1분 30초, 총량 100회입니다.
- 금요일은 20분 푸쉬업 기술 영상과 동작 간 15초 휴식을 따릅니다.
- 토요일 풀업 미션은 보조 35kg, 총 30회, 최대 10세트, 세트 간 1분 30초입니다.
- 일요일은 머신 중심 등 운동과 러닝머신을 진행합니다.
- 예리한 통증, 흉통, 심한 호흡곤란, 어지럼증이 생기면 즉시 운동을 중단합니다.

이 프로그램은 일반적인 운동 정보이며 의료 진단이나 치료를 대신하지 않습니다.
