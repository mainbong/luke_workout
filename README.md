# LUKE / 4주 운동 미션

운동 초보자가 한 달 동안 반복할 수 있는 주간 운동 프로그램과 기기 내 기록 도구입니다.
수·토·일만 이용 가능한 헬스장 일정과 현재 수행 수준을 반영했습니다.

## 실행

React 19, TypeScript 7, Vite 8 기반의 정적 프런트엔드입니다.

```bash
npm install
npm run dev
```

터미널에 출력된 로컬 주소를 브라우저에서 엽니다.

## 배포

GitHub Actions가 `main` 브랜치 변경을 감지해 Vite 빌드 결과를 GitHub Pages에 배포합니다.

저장소의 **Settings → Pages → Build and deployment**에서 Source를
**GitHub Actions**로 설정해야 합니다.

## 기록과 개인정보

- 완료 체크, 세트별 실제 횟수, 주차별 기록은 브라우저 `localStorage`에 저장됩니다.
- 기록은 현재 브라우저·기기에만 남으며 기기 간 동기화되지 않습니다.
- 브라우저 데이터 삭제, 시크릿 모드 종료, 사이트 저장소 초기화 시 기록이 사라질 수 있습니다.
- 실명, 체중, 사진 또는 민감한 건강정보를 수집하거나 전송하지 않습니다.
- “모든 기록 초기화”는 확인창을 거친 뒤 이 사이트의 기록만 삭제합니다.

## 프로젝트 구조

```text
.
├── src/
│   ├── App.tsx  # 화면, 기록 상태, 미션 계산, 90초 타이머
│   ├── data.ts  # 요일별 운동 프로그램
│   └── main.tsx # React 진입점
├── index.html   # Vite HTML 진입점
├── styles.css   # 7열 달력, 모바일 카드, 접근성
├── vite.config.ts
└── README.md
```

## 운동 프로그램 원칙

- 수요일은 주 등 운동, 토요일은 중간 강도 전신 볼륨, 일요일은 낮은 강도의 기술·회복으로 분리합니다.
- 대부분의 근력 세트는 폼이 무너지기 전, 약 2회 여유(RIR 2)를 남기고 끝냅니다.
- 풀업 미션은 보조 35kg, 24회부터 시작해 성공 시 3회 증가합니다.
- 푸쉬업 미션은 적절한 인클라인 또는 무릎 변형으로 40회부터 시작해 성공 시 5회 증가합니다.
- 예리한 통증, 흉통, 심한 호흡곤란, 어지럼증이 생기면 즉시 운동을 중단합니다.

이 프로그램은 일반적인 운동 정보이며 의료 진단이나 치료를 대신하지 않습니다.
